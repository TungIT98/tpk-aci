# Upload SEO Checklist — TKP Content Agency

> Every video must pass this checklist before publishing. The SEO Specialist owns this checklist. The Publisher executes it.
> Reference companions: `content/keyword-research.md`, `content/trending-topics.md`, `content/seo-briefs/Hashtag-Refresh-Guide.md`

---

## Definition of Done

A video upload has SEO **done** only when ALL items below are checked. Do not publish without full completion.

---

## Pre-Upload SEO Verification (done before video export)

### Title ✅
- [ ] Primary keyword appears in the first 60 characters
- [ ] Title matches an approved SEO title option from the video's brief (`content/seo-briefs/[BRIEF-ID].md`)
- [ ] No keyword stuffing — title reads naturally
- [ ] Power word or number included (where appropriate per brief)
- [ ] YouTube: 60 characters max (for full display in search results)
- [ ] TikTok: 100 characters max; front-load the hook

### Description — YouTube ✅
- [ ] Line 1: Hook (primary keyword + value prop, 1–2 sentences)
- [ ] Lines 2–4: 2–3 keyword-rich sentences (secondary keywords woven in naturally)
- [ ] "In this video you'll learn:" bullet list (3–4 points)
- [ ] Chapters/timestamps section (see Chapters section below)
- [ ] CTA to subscribe in final sentence
- [ ] Links: playlist link, related video, social links
- [ ] 2–3 relevant hashtags at bottom (below link block — not in description body)
- [ ] 150–250 words total

### Tags — YouTube ✅
- [ ] Primary keyword as first tag
- [ ] 8–15 additional tags (mix of broad + niche per brief)
- [ ] No duplicate tags
- [ ] No irrelevant tags or trademarked terms without permission

### Thumbnail — YouTube (coordinate with Designer) ✅
- [ ] Primary keyword or power word in overlay text
- [ ] High-contrast text, readable on mobile
- [ ] Face / expression shot (or approved graphic-only per channel)
- [ ] No misleading imagery — must accurately reflect content
- [ ] 1280×720 px, under 2MB, JPG or PNG
- [ ] Text under 5 words

### Thumbnail — TikTok / Reels ✅
- [ ] Hook text in first frame (1–3 words, high contrast)
- [ ] Visual hook: show the result, tension, or personality immediately
- [ ] Aspect ratio: 9:16 (1080×1920)
- [ ] Text optional for TikTok-native format; include if brief specifies

### Chapters / Timestamps ✅
- [ ] First chapter at 0:00 — must include primary keyword
- [ ] 3–8 chapters depending on video length
- [ ] Timestamps accurate to within 10 seconds
- [ ] Chapters exported as YouTube timestamp links in description

## Hashtag Refresh Protocol — TikTok / Reels (mandatory, 7 days before upload)

**This step must not be skipped. TikTok hashtag performance decays within days.**

Per `content/seo-briefs/Hashtag-Refresh-Guide.md`:
- [ ] **7 days before upload:** Search TikTok Discover for your topic keywords
- [ ] Note top 3–5 trending hashtags in your niche
- [ ] Update caption with refreshed hashtags
- [ ] **On upload day:** Re-verify trending hashtags — update caption again before posting
- [ ] Hashtag mix: 2 broad + 2 niche + 1 seasonal (max 8 hashtags total per TikTok)
- [ ] Hashtags NOT in the first line of caption (shadowban risk)

---

## Upload Day Checklist — Complete on Publish Day

1. [ ] **Final hashtag refresh** — Search TikTok Discover. Pull top 3 trending hashtags for your topic. Update caption.
2. [ ] **Trending sound check** — Search TikTok sounds for your topic. Apply if relevant.
3. [ ] **Description final read** — No broken links, correct timestamps, refreshed hashtags.
4. [ ] **Pin comment** — Draft from brief upload notes. Post manually 5 minutes after upload.
5. [ ] **Thumbnail** — Confirm correct version uploaded (A vs B if A/B testing).
6. [ ] **Share to secondary platforms** — Post YouTube link to Twitter/X and LinkedIn with platform-appropriate caption.

---

## Post-Upload SEO (within 1 hour of publish)

- [ ] Verify title appears correctly in YouTube search (search: title + primary keyword)
- [ ] Check suggested video adjacency (YouTube recommends relevant videos?)
- [ ] Confirm tags registered (YouTube Studio > Content > Details)
- [ ] Pin a keyword-rich comment (from brief upload notes)
- [ ] Share to secondary platforms with adapted hashtags

---

## Post-Upload Monitoring (within 48 hours)

- [ ] Verify video indexed: search YouTube for title + primary keyword
- [ ] Check thumbnail CTR: if below 2% in first 24 hours, flag for potential thumbnail swap
- [ ] Monitor comment sentiment — respond to top 5 comments to boost engagement signal
- [ ] Note algorithm issues (video not reaching subscribers) — flag to SEO Specialist
- [ ] Log first performance data to brief as a comment (CTR, views, search impressions)

## Per-Platform Upload Steps

### YouTube
- [ ] Upload video file (1920×1080, H.264, AAC audio)
- [ ] Set title (approved SEO title)
- [ ] Paste description (from brief template)
- [ ] Add tags (from brief)
- [ ] Add chapters as timestamp links in description
- [ ] Upload thumbnail
- [ ] Assign to playlist if applicable
- [ ] Set publish date/time:
  - Productivity Worker: Tuesday 8AM SGT / Monday 7PM EST
  - Gen Z Success: Tuesday 7PM SGT / Tuesday 7AM EST
- [ ] Set visibility: Public or Scheduled
- [ ] Add end screen: link to second video in series or most-viewed
- [ ] Add cards: link to related video at relevant timestamp

### TikTok
- [ ] Upload (1080×1920, under 3 minutes for best reach)
- [ ] Caption from brief template (hashtags updated on upload day)
- [ ] Apply refreshed hashtags + trending sound (same day)
- [ ] Toggle: Comments ON, Duet/Reactions ON, Stitch OFF if sensitive topic
- [ ] Schedule or publish

### Instagram Reels
- [ ] Same video as TikTok (or cut to IG-native format)
- [ ] Caption: same hook, same hashtags (max 30)
- [ ] First comment: add long-tail hashtags if caption is tight

### LinkedIn
- [ ] Native video upload (algorithm favors in-platform)
- [ ] Caption: "We" not "I"; hook in first line
- [ ] 3–5 career/industry hashtags
- [ ] Tag company page if applicable
- [ ] YouTube link in first comment

## Quick Reference: Keyword Placement

| Element | Rule |
|---------|------|
| YouTube title | Primary keyword in first 60 chars |
| YouTube description (opening) | Primary + 1 secondary keyword |
| YouTube tags | Primary first, then 7–14 supporting |
| YouTube chapters | First chapter includes keyword |
| TikTok caption | Primary keyword in first 2 sentences |
| TikTok hashtags | 2 broad + 2 niche + 1 seasonal (max 8) |
| LinkedIn caption | Hook includes keyword; "We" framing |

---

## SEO Anti-Patterns (never do these)

- Keyword stuffing in title or description
- Tag spam (unrelated high-volume tags)
- Misleading titles that don't match content
- Publishing without chapters/timestamps
- Skipping the hashtag refresh (7 days before upload)
- Using the same title format across all videos (YouTube rewards variety)
- Ignoring trending sounds on TikTok upload day
- First-line TikTok hashtags (shadowban risk)

---

## Escalation

Flag SEO Specialist immediately if:
- Video not indexed by YouTube within 72 hours of upload
- Thumbnail CTR below 1.5% after 24 hours
- Sudden algorithm change affecting a published video
- Title/description needs urgent revision based on performance data
- New trending topic overlaps with an upcoming video (rapid-response consideration)

## Post-Launch Ops Notes (added 2026-03-27)

### YouTube Shorts vs. Long-Form — Upload Differences

| Element | Long-Form (YouTube) | YouTube Shorts |
|---------|---------------------|----------------|
| Aspect ratio | 16:9 (1920×1080) | 9:16 (1080×1920) |
| Length | Any (pilot: 2–5 min) | Under 60 seconds |
| Chapters | Required | Not applicable |
| End screen | Required | Not applicable |
| Cards | Required | Not applicable |
| Thumbnail | Custom upload required | Auto-generated or custom |
| Description | Full SEO template | Short (125 chars) + hashtags |
| Tags | 8–15 tags | 3–5 hashtags in description |

**Shorts upload steps:**
- [ ] Upload as YouTube Short (select "Shorts" during upload, or use `youtube.com/shorts/[id]` after upload)
- [ ] Title: same hook as long-form, under 100 characters
- [ ] Description: hook sentence + 3–5 relevant hashtags (no chapters)
- [ ] No tags field required for Shorts
- [ ] Visibility: Public (Shorts feed, not browse feed)

### YouTube Studio — Pre-Launch Verification (one-time)

Before the first upload, Publisher must verify:
- [ ] YouTube channel verified (youtube.com/verify)
- [ ] Google Search Console verified for the channel domain
- [ ] Custom thumbnail size confirmed (1280×720, under 2MB)
- [ ] Channel keywords set: `#productivity` and `#careeradvice` (YouTube Studio > Customization > Basic info > Channel keywords)
- [ ] Default language set correctly (English)
- [ ] Upload defaults: High quality, show video info panel

### Community Post — Engagement Booster (within 1 hour of publish)

- [ ] Post a community poll or comment prompt in YouTube Studio Community tab
- [ ] Example: "Which would you add to your routine first — the 2-minute rule or time blocking? Comment below."
- [ ] Community posts appear in subscriber feed and boost algorithm signal
- [ ] Do this within 1 hour of upload while the video is fresh

### Indexing Verification Checklist (within 72 hours of publish)

- [ ] Search YouTube: type video title + primary keyword — video appears in results
- [ ] YouTube Studio > Content: video shows "Uploaded" status (not "Processing")
- [ ] If video not indexed within 72 hours: flag to SEO Specialist immediately
  - Check: title doesn't violate policy, thumbnail doesn't contain misleading claims
  - Fix: resubmit with minor title edit, re-check in 24 hours
  - Escalate: YouTube Studio > Help > Request review if indexing issue persists

### Analytics Setup — Pre-Launch (one-time)

- [ ] YouTube Studio > Analytics: bookmark the Overview, Reach, Engagement, and Revenue tabs
- [ ] Set up Google Alerts for channel name + primary keywords (flag weekly)
- [ ] Log into analytics/seo-performance-logger.js — first-run setup (see `content/analytics-playbook.md`)
- [ ] Publisher to log first video's CTR and impressions within 24 hours of publish

### Cross-Post Timing Refinements (added 2026-03-27)

**LinkedIn native video timing:**
- Optimal: Same day as YouTube upload, 7–9 AM local (SGT = 7–9 PM EST previous day)
- If not same day: post within 48 hours of YouTube upload for maximum algorithmic benefit
- Caption formula: Hook in line 1 ("We") → value statement in line 2 → CTA in line 3 → hashtags below

**Twitter/X cross-post timing:**
- Publish within 2 hours of YouTube upload
- Format: Hook tweet (1–2 sentences) + YouTube link + 2–3 relevant hashtags
- Pin tweet for 24 hours if tweet performs well

### Escalation — SEO Specialist Contact Triggers

Flag SEO Specialist immediately for any of the following:
- Video not indexed by YouTube within 72 hours
- Thumbnail CTR below 1.5% after 24 hours on YouTube
- TikTok video shows 0 views after 4 hours (possible shadowban or content policy flag)
- Sudden algorithm change affecting published videos
- Title/description needs urgent revision based on early performance data
- New trending topic overlaps with an upcoming video (rapid-response content flag)
- YouTube search impressions for primary keyword are zero — indicates indexing or keyword mismatch issue
