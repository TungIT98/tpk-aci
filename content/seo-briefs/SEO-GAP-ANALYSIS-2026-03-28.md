## 1. Format Inconsistency — WC-01 to WC-10

The World Cup SEO briefs have **two different formats** that need to be unified before upload:

### Format A — WC-01 to WC-05 (Older)
- Uses `## Primary Keyword` (singular, backtick-wrapped)
- Includes `## YouTube Tags` section (10–12 tags)
- Includes `## Chapters / Timestamps` table
- Separate TikTok hashtag breakdown: Broad / Niche / Seasonal
- Includes `## Upload Notes` with timing recommendations
- ✅ **Better for YouTube** — tags and chapters boost YouTube Shorts discoverability

### Format B — WC-06 to WC-10 (Newer)
- Uses `### Primary Keywords` (plural, bullet list)
- **Missing `## YouTube Tags` section** — critical gap for YouTube Shorts SEO
- **Missing `## Chapters / Timestamps`** — reduces YouTube watch time and discoverability
- Hashtags in single inline line (no Broad/Niche/Seasonal split)
- Includes `## Competitor Analysis` and `## Target Audience` — useful additions
- ✅ **Better for TikTok** — but loses YouTube optimization

### Recommendation
**Merge formats** — adopt the full Format A structure (YouTube Tags + Chapters) for all WC briefs, and add Format B's `## Competitor Analysis` and `## Target Audience` sections as optional additions.

## 3. Hashtag Issues in WC-06 to WC-10

### Problem 1: Casing Inconsistency
- WC-06/07/08 use `#WorldCup2026` (PascalCase) ✅
- WC-07 line 36: `#Football TikTok` — has a space, broken hashtag ❌
- WC-10: `#WorldCup2026 #PenaltyShootout #WorldCupDrama` — PascalCase mixed with Title Case

**Fix:** Standardize all hashtags to **Title Case** (e.g., `#WorldCup2026 #PenaltyShootout #FootballTikTok`)

### Problem 2: No Broad/Niche/Seasonal Split in WC-06-10
Format A (WC-01-05) separates hashtags into three tiers. This is important because:
- **Broad** (#worldcup, #soccer, #football) — max reach, high competition
- **Niche** (#fanbus, #goalreaction) — medium reach, better targeting
- **Seasonal** (#worldcup2026, #footballseason) — timely relevance boost

Format B briefs use a single inline hashtag list with no strategic tiering.

### Problem 3: Missing `#FIFA` in WC-01-05
WC-06-10 include `#FIFA` in hashtags. WC-01-05 do not. Both sets should include it.

## 9. SEO Brief Format — Standardized Template

For all future briefs, adopt this unified structure:

```markdown
# SEO Brief — [Title]

> Channel: [Channel Name]
> Status: Ready for Production
> Date: [YYYY-MM-DD]

---

## Primary Keyword
`[exact keyword phrase]`

## Secondary Keywords (2–3)
- [keyword 1]
- [keyword 2]
- [keyword 3]

## SEO Title Options
1. `[Option 1 — RECOMMENDED]`
2. `[Option 2]`
3. `[Option 3]`

## Description Template
```
[Full description with hook, body, bullets, CTA]
```

## YouTube Tags (10–12)
```
[keyword 1], [keyword 2], [keyword 3], [keyword 4], [keyword 5],
[keyword 6], [keyword 7], [keyword 8], [keyword 9], [keyword 10],
[keyword 11], [keyword 12]
```

## Chapters / Timestamps
| Timestamp | Chapter Title |
|-----------|--------------|
| 0:00 | [Chapter 1] |
| 0:03 | [Chapter 2] |
| 0:06 | [Chapter 3] |

## TikTok / Shorts Hashtags
- **Broad:** #[keyword1] #[keyword2] #[keyword3]
- **Niche:** #[keyword4] #[keyword5]
- **Seasonal:** #[keyword6] #[keyword7]

## Thumbnail Notes
- Text overlay: "[Text]"
- Expression: [Description]
- Color scheme: [Description]

## Upload Notes
- **Publish timing:** [Specific date/time recommendation]
- **Cross-post:** [Platforms]
- **Pin comment:** "[Comment text]"
- ⚠️ [Any special notes]

## Competitor Analysis *(optional)*
[Notes on competing content]

## Target Audience *(optional)*
[Audience description]
```
