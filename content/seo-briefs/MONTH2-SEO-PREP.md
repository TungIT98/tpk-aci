## YouTube SEO Recommendations (Month 2)

### Title Formula
Stick with high-CTR patterns from pilot:
- `"The [Number] [Topic] That [Outcome Verb]"` — proven pattern (e.g., PW-30)
- `"[Question nobody asks about] [Topic]"` — curiosity gap (e.g., GZ-36)
- `"I Did [X] for [Time Period] — Here's What Happened"` — authenticity hook

### Description Template
All Month 2 descriptions should include:
1. Primary keyword in first 25 words
2. Timestamp/chapters (5–8 chapters)
3. Secondary keywords in middle 100 words
4. CTA + playlist links at end

### Tag Strategy
- Primary keyword first
- 10–15 tags per video
- Include 2–3 broad tags (`productivity`, `career advice`)
- Include 2–3 long-tail tags (`how to time block at work`)
- Refresh tags for every upload
