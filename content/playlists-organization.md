## Upload Order Strategy

### Week 1–4 (Pilot Launch)

**TKP Productivity**:
```
Week 1: PW-01 (2-Minute Rule) + PW-02 (Meeting Damage)
Week 2: PW-03 (Sunday Ritual) + PW-04 (Email Trap)
Week 3: Time Systems deep-dive video
Week 4: Tool Stack intro video + Playlist cleanup
```

**TKP Growth**:
```
Week 1: GZ-01 ($3,200 Income) + GZ-03 (Career Advice)
Week 2: GZ-04 (AI Tools) + GZ-05 (POV $1K)
Week 3: Income Hacks follow-up
Week 4: POV series + Skill Stack intro
```

### Evergreen vs. Seasonal

| Type | Productivity | Growth |
|------|-------------|--------|
| Evergreen (always relevant) | Time Systems, Tool Stack, Mental Models | Income Hacks, Career Strategy, Skill Stacking |
| Trending (timely) | Meeting Culture (post-pandemic), AI tools | Money Mindset (inflation era) |
| Seasonal | Work-Life Integration (Jan: New Year routines; Sep: Back-to-work) | POV Series (always timely), Real Talk |

### Upload Order Algorithm

1. **New sub onboarding**: Start Here → most-viewed pillar playlist
2. **Watch time optimization**: Longest/highest-retention content at end of session (auto-play)
3. **Ad revenue**: Deep Dives / evergreen long-form go last in session (max watch time = max AdSense)
4. **Shorts funnel**: Shorts → short playlist → long-form playlist
5. **Cross-channel**: End screen on TKP Productivity → link to TKP Growth video (and vice versa after 30 days)

## Playlist Creation Steps (Operator)

After channels are live (TKP-29):

1. YouTube Studio → Playlists → **Create new playlist** (per playlist above)
2. Set visibility to **Public** once launch-ready (keep Private during launch week)
3. Add videos as they publish — or add pilot scripts as placeholders before upload
4. **Pin** "Start Here" playlist on channel page
5. Add playlists to channel page featured section: Playlists → "Add section" → select playlists
