# Thumbnail Design System — TKP Content Agency

> Design output for TKP-20. Thumbnail templates and guidelines for both channels.

---

## Overview

Both channels share a coherent parent brand (TKP) but have distinct visual identities within that family. Thumbnails should be instantly recognizable as from the same creator family while clearly signaling which channel.

---

## Channel 1: Productivity Worker

### Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Background | Warm off-white | `#F8F7F4` |
| Primary text | Deep navy | `#1A2744` |
| Accent | Warm gold | `#C9A84C` |
| Secondary | Slate gray | `#64748B` |

### Typography

- **Headline text**: DM Sans Bold / 900 weight
- **Sub-text**: DM Sans Medium
- **Min size**: Headline readable at 120px wide thumbnail

### Layout Grid

```
┌──────────────────────────────────────┐
│                                      │
│   [Icon/Photo zone — left 60%]       │
│   Minimal clutter                     │
│   Focus on single strong visual       │
│                                      │
├──────────────┬───────────────────────┤
│  [TKP logo   │                       │
│   indicator] │  BOLD CLAIM TEXT      │
│              │  (1–4 words max)       │
└──────────────┴───────────────────────┘
```

### Face Placement Rules

- **If face**: Position right side, looking toward center text
- **Expression**: Slightly raised eyebrow or neutral confidence
- **Crop**: Head + upper chest visible
- **Never**: Overwhelmed, stressed, or negative expression

### Text Overlay Rules

- **Max 3 words** in main headline
- **Max 8 words** in supporting line
- **Text position**: Bottom 40%, right-aligned
- **Drop shadow**: Always
- **Contrast**: WCAG AA minimum

### Approved Templates

1. **"System Screenshot"** — Clean Notion/Obsidian screen, bold claim overlay
2. **"Before/After Split"** — Cluttered desk vs. clean desk
3. **"Single Object + Text"** — Coffee cup OR clock OR calendar, minimal
4. **"Face + Text"** — Presenter right side, bold text left
5. **"Number Hook"** — Large number (e.g., "3 hrs") on minimal desk scene

### Never Do

- Cluttered backgrounds, more than 3 colors, decorative fonts, ALL CAPS (unless brand name), screenshots with browser chrome, blurry imagery, gamer-style neon effects

## Channel 2: Gen Z Success

### Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Background | Deep black | `#111827` |
| Primary text | Pure white | `#FFFFFF` |
| Accent 1 | Electric violet | `#7C3AED` |
| Accent 2 | Hot coral | `#FF6B6B` |
| Accent 3 | Neon yellow | `#FACC15` |

### Typography

- **Headline text**: Bebas Neue (bold condensed)
- **Sub-text**: Inter Bold
- **ALL CAPS** for main claim — expected by audience
- **Min size**: Readable at 90px wide thumbnail

### Layout Grid

```
┌──────────────────────────────────────┐
│  [COLOR ACCENT BAR — top 15%]        │
│  (gradient or solid brand color)     │
├──────────────────────────────────────┤
│   [Dynamic visual zone — center]      │
│   Face OR money/content image         │
│   High contrast, slightly cropped     │
├──────────────────────────────────────┤
│  ┌─────────────────────────────┐     │
│  │  BOLD CLAIM IN ALL CAPS     │     │
│  │  (2–4 words, centered)       │     │
│  └─────────────────────────────┘     │
│  [supporting text — smaller]          │
└──────────────────────────────────────┘
```

### Face Placement Rules

- **Position**: Center or slightly off-center
- **Expression**: Excited, surprised, confident
- **Crop**: Close-up face or 3/4 view — show emotion clearly
- **Always**: Big energy — no neutral/bored expressions

### Text Overlay Rules

- **ALL CAPS** for main claim
- **Max 3 words** in main headline
- **Use color blocks** (violet or coral rectangles) behind text
- **Emoji**: 1 max, in accent color only (🔥 💰)

### Approved Templates

1. **"Income Screenshot"** — Phone showing payment receipt, bold claim text
2. **"Face Reaction"** — Surprised/excited face close-up, bold text overlay
3. **"Before/After Money"** — $0 → $X, split panel, high energy
4. **"Bold Quote Card"** — Quote on dark background, accent color text
5. **"How Much I Made"** — Number overlay on lifestyle photo
6. **"POV Text"** — "POV:" style text card with Gen Z relatable scenario

### Never Do

- Pastel or muted colors, corporate backgrounds, serious expressions, more than 2 accent colors, small text, stock photo feel

## Cross-Channel Rules

| Spec | Value |
|------|-------|
| Format | PNG with transparency (preferred) or JPG |
| YouTube resolution | 1280×720 (16:9) |
| TikTok/Reels | 1080×1920 (9:16) |
| Color space | sRGB |
| File size | Under 2MB |
| A/B testing | Create 2–3 variants per video |
| Brand watermark | Bottom-left, 10% opacity, "TKP" |
