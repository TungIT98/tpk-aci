## PRODUCTION NOTES

### How to use these hooks
1. Pick a hook that matches your topic
2. Customize the specifics (name, number, industry detail)
3. Feed the HOOK into the script generator
4. The hook becomes the **first 3 seconds of visual + audio** in Hailuo prompt

### Hailuo visual cue for hook types
| Type | Visual Tone |
|------|-------------|
| Question | Eye contact, direct to camera, bold text overlay |
| Contrarian | Split screen or transition, surprise expression |
| Story | Close-up face, warm lighting, then scene cut |
| Stat | Phone/laptop screen showing data, quick cuts |
| Emotional | Golden hour/warm light, candid moment, wide shot |
