# CTA Strategy — TKP Content Agency

> Strategy output for TKP-22. Call-to-action playbook for both channels.

---

## Channel 1: Productivity Worker

### CTA Philosophy
CTAs should feel like helpful suggestions, not demands. The viewer has already gotten value — the CTA is "continue getting value." Never beg for subscribers. Earn them by implying there's more where that came from.

---

### In-Video CTA Moments

| Timestamp | CTA Type | Script Template | Goal |
|-----------|----------|----------------|------|
| Hook (0–3s) | Pattern interrupt | None — hook first | Stop scroll |
| Value delivery (mid) | Soft ask | "If you want more of this, the playlist is linked" | Retain viewer |
| Pre-ending (45s before) | Strong ask | "Hit subscribe and tap the bell — next week I'm doing [specific next video]" | Subscriber |
| Final frame (last 3–5s) | Action + reason | "Subscribe — next week: [specific outcome]" | Subscriber |

### Subscribe CTA

**Primary formula**: Specific next-video preview + reason to believe.

```
"If you want [specific result they'll get next video], subscribe
 and I'll see you next [day/week]."
```

**Secondary (opinionated)**:
```
"Don't subscribe just yet — watch 30 more seconds and decide for yourself."
```
→ Used on evergreen educational content where the first video proves itself.

**Taboo for Channel 1**:
- "If you made it this far, subscribe!" — lazy
- "Like and subscribe please" — too casual
- "I post every [Monday]" — only say if 100% consistent

---

### End-Screen Strategy (YouTube)

Reserve end-screen real estate for:
1. **Playlist** (most valuable) — link to related content people will watch next
2. **Another video** (second most) — single related video
3. **Subscribe button** (use sparingly) — only if channel needs sub push

Never waste end screen on a video from 6 months ago.

---

### Description CTA (YouTube + LinkedIn)

First 2 lines of description show in pre-roll preview — make them count:

```
// GOOD
"The system I use instead of a to-do list → [tool link]
Watch next: [video title] → [link]
"

// BETTER — drives saves
"Save this post — I reference this system every single week.
Tool: [link]
Related: [video/playlist link]
"

// LinkedIn specific (first person, professional, no emoji spam)
"Save this thread. I reference it every Monday planning session.
My weekly review template: [link]
```

---

### Community Tab CTA (YouTube)

Community posts drive 30-day retention. Use for:
- Polls: "Which topic next? A) [Topic A] B) [Topic B]"
- Questions: "What's your biggest challenge with [topic]? I'm reading replies."
- Preview posts: "Thursday's video is about [X] — who relates?"

Frequency: 1–2x per week, never post without a question or choice.

---

### Playlist Strategy

Create playlists that give "what to watch next":

```
Channel 1 playlists:
- "Time Management Fundamentals" (5–7 videos)
- "My Full Tool Stack" (3–4 videos)
- "Deep Work Starter Kit" (4 videos)
```

Link relevant playlist at end of every applicable video.

## Channel 2: Gen Z Success

### CTA Philosophy
Gen Z responds to CTAs that feel like inside jokes or tribe signals, not corporate asks. "Follow for more" is a social identity statement, not a subscription request. Save CTAs should be framed as "this is useful" not "please save."

---

### In-Video CTA Moments

| Timestamp | CTA Type | Script/Format | Goal |
|-----------|----------|--------------|------|
| Hook | None | Open with value first | Stop scroll |
| Core value (mid-video, 15s) | Soft follow | "Follow if you want more [specific type]" | Follow |
| Pattern-interrupt (random) | Relatable meme + "follow" | Visual punchline | Follow (low pressure) |
| Final frame | Dual CTA | "Follow + save this" | Both |

---

### Subscribe / Follow CTA

**Primary formula** — identity-driven:

```
"Follow — I post [specific content type] every [day/week]
 that [specific outcome you'll help them achieve]."
```

**Secondary (save-driven)**:
```
"If you found this useful, save it — your algorithm won't show it twice."
```
→ Drives saves, which signals relevance to the algorithm.

**Final frame example**:
```
"Follow and turn on notifications 🔔
I post real career + money stuff. No guru BS."
```

**Taboo for Channel 2**:
- "Please follow me" — too desperate
- Any CTA that sounds like LinkedIn
- Long explanations of why they should follow — show, don't tell

---

### TikTok Platform CTAs

TikTok favors high save rates. Frame saves as self-interest:

| Don't Say | Do Say |
|-----------|--------|
| "Save this video" | "Save this — you'll forget otherwise" |
| "Follow for more" | "Follow. Trust me." |
| "Like and follow" | Nothing — let quality speak |

Best TikTok CTA format: **relatable statement + follow signal**
```
"You just learned [X]. Your feed won't show you this twice.
Follow — I post 3x/week."
```

---

### Instagram Reels CTAs

Instagram is save-first, follow-second:
```
"Screenshots don't count as saving.
Hold that share button 📤"
```
```
"Saving this is your future self saying thank you."
```

---

### YouTube Shorts CTAs

Shorts audiences rarely subscribe — optimize for follows and saves:
```
"Full video on this topic is on my channel — link in bio."
```
```
"I have a whole series on [topic] — start here."
```

---

## Cross-Platform CTA Rules

1. **One CTA per video** — Two CTAs split the ask and reduce both. One clear ask wins.
2. **Match CTA to content completion rate** — High drop-off = softer CTA. Low drop-off = stronger ask.
3. **Never lie about posting frequency** — If inconsistent, say nothing.
4. **Track CTR by CTA type** — Rotate CTA styles monthly and watch analytics.
5. **Link in bio > in-video CTA** — Most conversions happen post-watch via link-in-bio tools (Linktree, Taplink).
