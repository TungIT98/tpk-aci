> TKP-33 supporting design. Thumbnail specs for both trailer videos.

## Overview

Each trailer needs **3 thumbnail variants** for A/B testing per YouTube/algorithm best practices.
All specs below. Files to be generated after video is rendered (frame grabs + text overlay).

### Thumbnail A — "The Problem" (Strongest CTR Prediction)

**Concept**: Chaos vs. calm split. Before/after in a single frame.
**Recommended frame grab**: Scene 4 (phone face-down, breath moment) — the turning point.
**Overlay**: Left half shows cluttered desk blur; right half shows clean desk sharp.

| Element | Spec |
|---------|------|
| Format | PNG with transparency or JPG |
| Resolution | 1280×720 (16:9 YouTube) |
| Main text | "Stop Doing This" or "Your Focus Is Gone" |
| Text size | Headline: 60–72px DM Sans Bold |
| Text color | White `#FFFFFF` with drop shadow |
| Accent | Gold `#C9A84C` underline on text |
| Brand mark | Small TKP logo bottom-left, 10% opacity |
| Background | Frame grab from Scene 4 (turn moment) with slight darkening |
| A/B note | Use "Stop Doing This" for higher CTR on 25–35 demo |

**Layout**:
```
┌──────────────────────────────────────┐
│ [Darkened frame grab: turn moment]    │
│                                       │
│  "STOP DOING THIS"     [TKP logo]    │
│  ─────────────                         │
│  Your focus is already gone.          │
└──────────────────────────────────────┘
```

## Technical Specs (All Variants)

| Spec | Value |
|------|-------|
| File format | PNG (transparency preferred) or high-quality JPG |
| YouTube resolution | 1280×720 (16:9) |
| TikTok/Reels | 1080×1920 (9:16) |
| Color space | sRGB |
| File size | Under 2MB |
| Text min size | Readable at 120px wide (YouTube), 90px wide (TikTok) |
| Drop shadow | Always on text overlays |
| Brand watermark | "TKP" — bottom-left, 10% opacity |
| A/B test | 2–3 variants per video — swap every 48 hours based on CTR |
