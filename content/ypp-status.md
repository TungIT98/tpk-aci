## Action Plan

### Immediately (Pre-First-Video)
- [ ] Enable 2-Step Verification on both channels
- [ ] Create AdSense accounts for both channels
- [ ] Set channel associated country correctly in YouTube Studio
- [ ] Configure YouTube API keys in `.env` (see `content/analytics-playbook.md`)

### Once First Videos Are Live
- [ ] Monitor YouTube Studio analytics daily for first 2 weeks
- [ ] Track subscriber conversion rate: target ≥3% of views → subs
- [ ] Flag when either channel reaches 25% of any YPP threshold
- [ ] Begin weekly YPP progress logging in this file
- [ ] Enter per-video CTR and retention data after each video's first 7 days

### Threshold Alerts
- [ ] **25% milestone** (250 subs or 1,000 watch hrs) — review early performance
- [ ] **50% milestone** (500 subs or 2,000 watch hrs) — intensify content cadence
- [ ] **75% milestone** (750 subs or 3,000 watch hrs) — link AdSense account
- [ ] **100% milestone** (1,000 subs + 4,000 watch hrs) — apply for YPP immediately
