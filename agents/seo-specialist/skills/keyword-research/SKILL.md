# Keyword Research Skill

## Keyword Research Process

### Step 1 — Discover Keywords
```bash
# TikTok search suggestions
WebSearch(query="xianxia trending hashtags Vietnam 2026")

# YouTube search autocomplete
WebSearch(query="xianxia chinese drama youtube vietnam 2026")

# Competitor analysis
WebSearch(query="xianxia tiktok viral videos trending")
```

### Step 2 — Evaluate Keywords

| Metric | Good | Bad |
|--------|------|-----|
| Search volume | High | Zero |
| Competition | Low-Medium | Saturated |
| Intent | Watch/Entertain | Commercial |
| Relevance | High | Low |

### Step 3 — Apply Keywords

**Title Format (TikTok):**
```
[Xianxia Episode Title] | Part [N]
```
Max 60 chars, keyword at front.

**Title Format (YouTube):**
```
Xianxia: [Episode Title] | Trieu Tien EP[N]
```
Max 60 chars, keyword at front.

**Tags (TikTok):** 3-5 hashtags
```
#xianxia #truyencotich #phimcoso #viral #trending
```

**Tags (YouTube):** 10 tags max
```
xianxia, chinese drama, truyen co tich, viet nam,
fantasy, Trieu Tien, phim, giai tri, trending, viral
```
