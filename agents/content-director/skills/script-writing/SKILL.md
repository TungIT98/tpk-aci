# Script Writing Skill

## Script Structure
```
{
  "status": "pending",
  "theme": "...",
  "hook": "...",
  "prompt_for_hailuo": "...",
  "specific_details": {
    "subject": "...",
    "outfit": "...",
    "action": "...",
    "setting": "..."
  },
  "visual_scene": "...",
  "duration": 60
}
```

## Quality Criteria
- Hook: Strong, attention-grabbing first 3 seconds
- Body: Clear value proposition
- CTA: Actionable end card
- Visual: Detailed enough for AI generation

## Themes
- Productivity Worker (9-to-5 professionals)
- Gen Z Success (18-28, side-hustles, creator economy)
