# Quality Assurance Skill

## Video Quality Gates

### Pre-Production
- Script quality check (prompt detail level)
- Hashtag relevance check
- Content pillar alignment check

### Post-Production (Before Upload)
- [ ] Video file exists at expected path
- [ ] File size > 1MB
- [ ] Duration 45-90 seconds (Xianxia format: 30s)
- [ ] Aspect ratio 9:16 vertical
- [ ] Visual QC: content matches script prompt
- [ ] Hash differs from previous videos

### Post-Upload Verification
- Verify YouTube URL exists
- Verify TikTok URL exists
- Check thumbnail quality
- Verify title/description/captions applied

## Pipeline Quality Audits
- Check Content Director script quality trends
- Check Nova video consistency
- Check Production Manager upload success rate
- Track QC rejection rate per agent

## Quality Metrics
- QC pass rate
- Upload success rate
- Content matching accuracy
- Platform compliance (copyright, community guidelines)
