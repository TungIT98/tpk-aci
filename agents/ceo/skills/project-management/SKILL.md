# Project Management Skill

## Task Tracking
1. Create clear, actionable tasks with deadlines
2. Assign to right agent based on role
3. Follow up on blocked tasks
4. Update status in real-time

## Workflow
- CEO → Content Director → Scripts
- CEO → Nova → Videos
- CEO → Production Manager → Upload
- CEO → Founding Engineer → Dev

## Escalation
- Blocked > 2 heartbeats → escalate
- Quality issues → QA gate
- Timeline risks → CEO review
