# Pipeline Development Skill

## Tech Stack
- Node.js (video pipeline)
- Python (data processing)
- FFmpeg (video editing)
- n8n (workflow automation)

## Key Files
- `lib/video-pipeline.js` - Main pipeline
- `lib/hailuo.js` - Hailuo integration
- `lib/tts.js` - TTS generation
- `scripts/n8n_tiktok_workflow.json` - TikTok upload

## Common Tasks
- Fix Hailuo API errors
- Optimize FFmpeg commands
- Debug n8n workflows
- Add new platform integrations
