### Issue Fixed: BOM Pollution in 40 Script Files
**Problem:** Many JSON files in `scripts/pending/` had UTF-8 BOM (`\uFEFF`) at start of file. This caused `Unexpected token '﻿''` errors when read with `JSON.parse()` directly.

**Root Cause:** Windows text editors (likely Vietnamese input tools) save `.json` files with UTF-8 BOM. Node.js `JSON.parse()` does not strip BOM automatically.

**Fix Applied:** Stripped BOM from all 40 affected files:
```
COM-02, COM-03, COM-04, COM-06, GZ-01_10k-skill, GZ-03_dm-jobs, GZ-05_rich-habits,
GZ-06, GZ-09, GZ-10, GZ-11, GZ-12, GZ-17, GZ-SPECIAL, HGF-07, HGF-08, HGF-10,
HGF-12, HGF-15, LIFE-02, LIFE-03, LIFE-04, LIFE-05, PW-06 through PW-12,
TECH-02, TECH-03, TECH-05, TECH-06, TECH-07, TECH-08, TECH-09, TECH-10, TECH-12, VID-001
```
**Verification:** All 95 scripts now valid JSON. Batch upload uses BOM-strip before parse, so was working despite issue — but scripts that directly use `JSON.parse()` would fail.

**Prevention:** Configure editors to save UTF-8 without BOM, or use `content.replace(/^\uFEFF/, '')` before parsing.
