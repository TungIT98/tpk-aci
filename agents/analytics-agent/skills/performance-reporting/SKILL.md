## Monthly Report Structure

Save to: `content/reports/monthly/MONTHLY-2026-04.md`

```markdown
# Monthly Performance Report — April 2026

## Overview
[Month summary with charts]

## Platform Growth
[Month-over-month comparison]

## Content Performance
[Top 5 videos of the month]

## Revenue
[AdSense estimates, creator fund]

## Content Strategy Evaluation
- What worked: [insights]
- What didn't: [insights]

## Strategic Recommendations
[CEO-level recommendations for next month]
```

## Insight Quality Standards

### Must Include
- Specific numbers with date ranges
- Platform source identified
- Comparison to previous period
- Top 3 actionable insights

### Must Avoid
- Vague statements ("content is doing well")
- Metrics without context ("1000 views" without comparison)
- Recommendations without data support
